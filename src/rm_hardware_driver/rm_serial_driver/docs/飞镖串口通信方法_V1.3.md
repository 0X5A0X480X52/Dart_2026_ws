# 飞镖串口通信方法

## 视觉端串口数据结构定义

**📦小电脑数据发送端:**

有一个包头0x05，占1个字节

有一个**crc8校验**的包尾，占1个字节。校验仅校验数据有效部分，**不会校验包头**

不考虑包头包尾，共**13**个字节

数据包共**15**个字节

```cpp
# pragma pack(push, 1)
struct SerialSendData {
    // 目标距离
    float Distance;

    // 像素误差
    // 计算公式：检测框的水平像素-理想点的水平像素
    // 即偏左时<0，偏右时>0
    int Pixel_Error;

    // 是否启用调试模式（true: 启用，false: 不启用）
    bool Debug_Mode;

    // 设定的发射拉力值
    int Shoot_Force_Set;
}
```

⚠️关于调试模式：

- 启用时：通过串口从c板接收SerialReceiveData，并启动可视化程序，支持通过窗口修改Shoot_Force_Set的值
- 不启用时：不会从串口接收数据，仅发送SerialSendData，此时Shoot_Force_Set的值是无效值

**📦小电脑数据接收端:**

不考虑包头包尾,共**12**个字节

数据包总长**15**个字节（与发送的数据包对齐）

```cpp
# pragma pack(push, 1)
struct SerialReceiveData {
    // 初始拉力值
    int Shoot_Force_Init;

    // 当前拉力值
    int Shoot_Force_Cur;
    
    //发射速度
    float Shoot_Vel;
}
```

结构体具体定义在文件`../include/serial_struct/serial_struct.hpp`里
